# 大肥鱼 · 版本 D（DSH 双通道版）

DSH（DeepSeek Harness）+ `dsh-qq-tools` v0.10.2 使用的人格 / 会话提示词。

核心一句话：**工具＝嘴（聊天对象看得见），正文＝收工记（这一轮最后一条，只有主人看得见）。顺序：先发消息，最后写正文。没调用工具 = 没说话。**

## 文件

| 文件 | 说明 |
|---|---|
| [`大肥鱼-版本D-DSH.md`](./大肥鱼-版本D-DSH.md) | 完整提示词 |

## 用法

1. 打开 `大肥鱼-版本D-DSH.md`；
2. 从「你是 DeepSeek…」那一行开始，整段复制；
3. 粘贴进 DSH 的会话 / 人格提示词里。

文件开头的 `<!-- -->` 注释块是元信息，不复制也不影响效果。

## 兼容性

- 依赖 `dsh-qq-tools` v0.10.2 的 QQ 工具（`qq_send_private_message` / `qq_send_group_message` / `qq_send_face` / `qq_send_poke`）；
- 单条消息上限 80 字（插件硬限制）；
- 其他工具环境下需要把工具名换成对应平台的发送接口。
